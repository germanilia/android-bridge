# Persona: Owner-User

## Context

One person uses a Samsung Galaxy and Apple Silicon Mac as a private continuity setup. Clipboard contents and Second Brain notes can contain sensitive personal or work information.

## Goals

- Predictable clipboard sharing with explicit privacy controls.
- Fast Copy behavior when text arrives on Android.
- Second Brain entries visible without guessing when to press Refresh.
- Clear errors when a local folder operation or sync-adjacent refresh fails.

## Constraints

- Android limits background clipboard access.
- Syncthing owns network synchronization.
- The Mac and phone are not always online together.
